应用程序说明（本项目以源码形式提供）
====================================

课程要求里的"应用程序"这一项，本项目**不提供独立的 exe**，而是：

1. **源码运行**：Windows / macOS / Linux 上装好 Python 3.12+ 与 pygame 2.6.1 后，
   执行 `python main.py` 即可进入选关界面（详细步骤见上一层目录的 `运行说明.txt`）。
2. **演示视频**：`提交材料/演示视频/递归之箱_演示_董长坤.mp4`（44.7 秒，H.264 mp4，
   Windows 可以直接播放），完整演示了两关的通关过程。

这样处理的原因：项目用 Python + pygame 实现，源码即程序；单独分发 Windows 可执行文件
需要额外的打包链与代码签名，对本课程作业不是必要环节。

如果之后确实需要 exe（例如老师要求双击即玩），可在 Windows 上装 pyinstaller 后重新打包，
或让我恢复打包脚本（约 10 分钟）。
