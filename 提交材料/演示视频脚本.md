# 演示视频录制脚本（Mac 录屏）

## 录制前 5 分钟

1. 关掉微信 / QQ / 系统通知（专注模式），静音手机；桌面别放隐私文件。
2. 终端执行（窗口内容固定 1280×720，录屏区域就框这个窗口）：

   ```bash
   cd ~/Desktop/box && source .venv/bin/activate && python main.py
   ```

3. QuickTime Player → 文件 → 新建屏幕录制 → 选「录制所选部分」→ 框住游戏窗口（约 1280×720）。
4. 先空跑一遍流程再正式录。
5. 录完导出 1080p：文件 → 导出为 → 1080p → 命名 `递归之箱_演示_董长坤.mp4`。

**总时长目标 2 分～2 分 30 秒。** 全程不用讲话也可以（也可后期配音，讲稿见文末）。

## 分镜表

| 镜头 | 时长 | 操作 | 画面要点 |
|---|---|---|---|
| 1 选关界面 | 10s | 启动后停住，`↑`/`↓` 切换一下 | 两张关卡卡片、关卡名「测试」「吞食01」与提示 |
| 2 「测试」关 | 25s | `Enter` 进入 → 连按 `↑ ↑ ↑ ↑ ↑` | 推箱 → 顶着箱子按方向键**钻进去**（地面深灰变深黄、HUD 出现 `当前层：外层 › b1`）→ 在内层把箱子推上 `g`（**描边发亮**）→ 通关遮罩显示总步数 |
| 3 撤销 / 重置 | 10s | 按 `U` 两次，再按 `R` | 步数从 5 递减 → 归零复位 |
| 4 「吞食01」 | 60s | `Enter` 进第二关，照下面序列按 | 重点看四个瞬间（见下一节） |
| 5 通关与返回 | 10s | 停在通关画面 → 按 `Enter` | 通关遮罩 + 总步数 37；`Enter` 回选关 |
| 6（可选）终端 | 20s | 切终端跑 `.venv/bin/python -m unittest discover tests` | 108 个用例全绿——"AI 写的代码由测试验收" |

### 镜头 4 的按键序列（37 步，BFS 解算器给出的最短解，照着按必通）

```
↑ ← ↓ → → → ↓ ← ← ↓ ← ↑ → ↑ ← ← ↑ ← ← ↓ → → → → ↓ → → ↑ ← ↓ ← ↑ ↑ ↓ ↓ ↓ ←
```

## 必须让观众看清的四个瞬间

| 步 | 画面 | 讲解点 |
|---|---|---|
| 3 | 方块 A 被推离判定点，`g` 从 1/2 变 0/2 | 得先把压在判定点上的箱子推开 |
| **9** | 普通方块被**吸进 A 的口**，从外层消失 | **吞食**：方块被推进另一个方块的口 |
| **15** | 玩家钻进 A，**整片地面变深黄** | 嵌套世界：方块内部是另一个可以走进去的世界 |
| **23** | 方块从内层**被推出到外层** | **双向穿口**：同一个口进出 |
| 24 | 玩家退出外层 | 跨层冻结：人在里面时外层完全不动 |
| 33 | 第二个方块压上 `(3,1)` 的 `g`，显示 2/2 | 两个箱子判定点全部盖上 |
| 37 | 玩家站上 `G`，通关 | 双条件判定：箱子 `g` + 玩家 `G` |

> 注意：这一版**通关画面上按 U/R 无效**（只认 `Enter` / `ESC`），录到那里按 `Enter` 返回即可，别在镜头里按 U/R。

## 镜头 6 的终端命令（可选，但很推荐）

```bash
cd ~/Desktop/box && source .venv/bin/activate
python -m unittest discover tests
```

输出应看到 `Ran 108 tests ... OK`。
