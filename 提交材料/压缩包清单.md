# 压缩包清单

## 命名

```
递归之箱.zip
```

一键生成：`.venv/bin/python 提交材料/打包提交材料.py`
产物默认放在 `提交材料/递归之箱.zip`（已加入 `.gitignore`，不会进仓库）。

## 一定要排除的东西（打包脚本已自动排除）

- `.venv/`（80MB 虚拟环境）、`.venv-build/`
- `__pycache__/`、`*.pyc`、`.DS_Store`
- `dist/`、`build/`、`.pyinstaller-cache/`
- 原始录制 `演示视频.mov`（4.5MB，已 gitignore；包内放转码后的 mp4）
- 生成的 zip 本身（`*.zip`，避免套娃）

## 体积参考

| 内容 | 实际/预计 |

## 提交材料目录里的脚本（都可重复运行）

| 脚本 | 作用 |
|---|---|
| `生成个人文档HTML.py` | Markdown → A4 打印版 HTML（5 页分页固定） |
| `生成个人文档PDF.py` | Markdown → A4 PDF（含 `--measure` 逐节测高，防超页） |
| `打包提交材料.py` | 组 zip + 清单自检（视频/PDF/exe 是否到位） |
