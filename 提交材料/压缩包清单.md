# 压缩包清单（组号确定后照着组）

## 命名

```
<组号>递归之箱.zip          例：B01递归之箱.zip
```

组号未知时先按 `递归之箱.zip` 打包，确定后改名即可（Release 附件可删掉重传）。

## 目录结构

```
<组号>递归之箱.zip
├── 01_源工程/
│   ├── 递归之箱/                     ← 仓库内容（不含 .venv）
│   │   ├── main.py  src/  levels/  tests/
│   │   ├── assets/  screenshots/
│   │   ├── AGENTS.md  RULE.md  README.md
│   │   ├── .dsh/skills/              ← 4 份 SKILL.md
│   │   └── .git/                     ← 建议一起给（2.6MB），能自证版本演化
│   └── 历史版本/                      ← 提交材料/历史版本/ 整个拷进去
│       ├── 00_版本演化总览.md
│       ├── AGENTS_v1..v8.md  RULE_v1..v3.md
│       ├── SKILL_push-box-logic_v1.md  SKILL_nested-world_v1.md
│       ├── SKILL_world-rendering_v1..v5.md  SKILL_level-loading_v1..v3.md
│       └── test_logic_v1..v4.py  test_world_v1..v2.py  test_render_v1..v4.py
├── 02_应用程序/
│   ├── RecursiveBox.exe              ← Windows 双击即玩（你已打好的那个）
│   └── 运行说明.txt
├── 03_演示视频/
│   └── 递归之箱_演示_董长坤.mp4
├── 04_汇报PPT/
│   └── 递归之箱_结课汇报_董长坤.pptx  （可把开题/阶段汇报一并放）
└── 05_个人文档/
    └── 递归之箱_个人文档_董长坤.pdf    ← 由 个人文档_董长坤.html 打印
```

## 一定要排除的东西

- `.venv/`（80MB 虚拟环境）、`.venv-build/`
- `__pycache__/`、`*.pyc`、`.DS_Store`
- `dist/`、`build/`、`.pyinstaller-cache/`（本机构建产物，已随打包改造回退删除）
- `selftest_report.txt`、`trace_log.txt`、`crash_log.txt`（自检与诊断输出）

## 体积参考（不含视频）

| 内容 | 约 |
|---|---|
| 源码 + 规则 + 测试 + 截图 | 3 MB |
| `.git`（含全部历史） | 2.6 MB |
| 历史版本导出（31 个文件） | 0.4 MB |
| 程序 exe | 14 MB |
| 汇报 PPT（3 份） | 0.7 MB |
| 个人文档 PDF | < 1 MB |
| **合计** | **约 22 MB** |

视频通常 20～80MB；若嫌大，可把视频作为**单独的 Release 附件**，zip 里只留一个说明文件指向它。
