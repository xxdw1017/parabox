# 提交步骤（照这个顺序做）

## 第 0 步：先把材料推上 GitHub

材料已放在 `box/提交材料/`。在 VS Code 里 commit 并 Sync（或命令行 `git push`）即可。
推送后仓库 HEAD 就是最终源工程。

## 第 1 步：把仓库改成公开

1. 打开 <https://github.com/xxdw1017/parabox> → 右上角 **Settings**
2. 左侧 **General**，页面拉到最底 **Danger Zone**
3. **Change repository visibility** → **Change visibility** → 选 **Make public**
4. 弹窗里按提示输入仓库名 `parabox` 确认 → **I understand, change repository visibility**

**公开前的自查（已确认过）**：

- `.venv/`（80MB 虚拟环境）没有被提交，`.gitignore` 已排除；
- 仓库里没有密码、token、密钥；没有与作业无关的隐私文件；
- 仓库体积约 2.6MB，历史里没有大文件；
- `assets/` 里的 logo 属于原游戏，README 末尾已有版权声明（学习用途、不作商用）。

改成公开后，GitHub Actions 分钟数对公开仓库免费（本项目未使用 CI，无影响）。

## 第 2 步：让"下载得到的压缩包"叫对名字

**先说事实**：GitHub 网页上 `Code → Download ZIP` 的文件名是 `仓库名-分支名.zip`，当前是
**`parabox-main.zip`**，这个自动生成的名字**无法直接修改**。要得到课程要求的
`<组号>递归之箱.zip`，用下面任意一种：

| 做法 | 得到的文件名 | 说明 |
|---|---|---|
| **推荐：发 Release，把改好名的 zip 当附件** | 完全等于附件名，例如 `B01递归之箱.zip` | 下载名 100% 可控，老师点一下就能下 |
| 改仓库名（只能 ASCII） | `B01-parabox-main.zip` | Settings → General → Repository name；旧链接会自动跳转；**仓库名不允许中文** |
| 改默认分支名 | `parabox-B01.zip` | 改 `main` 分支名，会打乱习惯，不推荐 |

**Release 具体操作**：

1. 仓库页右侧 **Releases** → **Draft a new release**
2. **Choose a tag** → 输入 `v1.0` → **Create new tag**
3. **Release title**：填 `递归之箱（<组号>）`
4. 把本地改好名的 zip **拖进附件区**（Attach binaries）
5. **Publish release** → 之后把 Release 页面链接放进提交栏

> 组号以后才确定也没关系：Release 附件可以删掉重传，改个名字即可。

## 第 3 步：组 zip（组号确定后，一次做完）

目录结构与命名见 **`压缩包清单.md`**。要点：

- 必须包含：源工程（含规则文件与测试）、应用程序、演示视频、汇报 PPT、个人文档；
- **不要把 `.venv/`（80MB）打进去**；`dist/`、`__pycache__/` 也不要；
- 视频很大时可以单独作为第二个 Release 附件，避免 zip 过大。

## 第 4 步：个人文档导成 PDF

1. 双击打开 `提交材料/个人文档_董长坤.html`（浏览器）
2. `Cmd + P` → 目标选 **存储为 PDF** → 纸张 **A4** → 边距 **默认** → 保存
3. 命名 `递归之箱_个人文档_董长坤.pdf`，放进 `05_个人文档/`

打印预览里应是 **5 页**；若某页溢出，把该页内容删减一两行即可（文档已用分页符固定为 5 页）。

## 第 5 步：发提交栏

用 `提交帖模板.md` 的内容：系统描述 + 两张运行截图 + GitHub（含 Release）链接。

## 交付前自检清单

- [ ] `git push` 完成，GitHub 上的 HEAD 与本地一致
- [ ] 仓库已公开，匿名访问 <https://github.com/xxdw1017/parabox> 能看到代码
- [ ] Release `v1.0` 已发布，附件名符合 `<组号>递归之箱.zip`
- [ ] 包内含源工程 / 程序 / 视频 / PPT / 个人文档五项
- [ ] 个人文档 PDF 为 5 页以内，含两处流程图（架构图、按键判定流程图）
- [ ] 提交栏里系统描述 ≤300 字、运行截图 1–2 张、链接可点开
- [ ] 在**别的电脑**上验证过：下载 zip → 双击 exe 能进入选关界面
