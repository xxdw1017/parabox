《递归之箱》运行说明（Windows / macOS）
=========================================

一、Windows
------------
本项目不提供独立 exe，Windows 上按下述步骤跑源码（约 2 分钟）：

    python -m venv .venv
    .venv\Scripts\activate
    pip install pygame==2.6.1
    python main.py

（若已装 Python 3.12+ 与 pygame，直接 `python main.py` 即可；只想看效果可以直接
 播放 03_演示视频 里的 mp4。）

操作：
     方向键 / WASD   移动、推箱子；站在方块的口那侧、方块推不动时按方向键 = 进入方块内部
     U              撤销一步
     R              重置本关
     ESC            返回选关（在选关界面按 = 退出）
     Enter          选关界面开始游戏 / 通关后返回选关
注意：本版**通关画面上按 U / R 无效**，请按 Enter 返回选关。

二、macOS / Linux（跑源码）
---------------------------
    cd 递归之箱
    python3 -m venv .venv
    .venv/bin/python -m pip install pygame==2.6.1
    .venv/bin/python main.py

    跑测试： .venv/bin/python -m unittest discover tests

三、关卡
--------
    「测试」    最短 5 步：推箱 → 钻进方块 → 在内层把箱子推上判定点
    「吞食01」  最短 37 步：把方块吞进另一个方块的口，再进箱子把它推出来
    两个判定点都要被方块盖住，玩家还要站上 G 才能通关。

四、常见问题
------------
- 启动报 ModuleNotFoundError: No module named 'pygame'：没装 pygame，按上面第一节装一次即可。
- 中文显示成方块：目标机器缺少中文字体（Windows 一般自带微软雅黑）。
- 没有声音：当前版本没有音效（开题时列为选做）。
- 把箱子推进死角：按 R 重置本关即可。
