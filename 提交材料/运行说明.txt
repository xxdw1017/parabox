《递归之箱》运行说明（Windows / macOS）
=========================================

一、Windows（推荐，无需安装任何东西）
-------------------------------------
1. 双击 02_应用程序\RecursiveBox.exe
2. 若弹出「Windows 已保护你的电脑」（SmartScreen）：点「更多信息」→「仍要运行」
   （exe 未做代码签名，属正常提示，不是病毒）
3. 操作：
     方向键 / WASD   移动、推箱子；站在方块的口那侧、方块推不动时按方向键 = 进入方块内部
     U              撤销一步
     R              重置本关
     ESC            返回选关（在选关界面按 = 退出）
     Enter          选关界面开始游戏 / 通关后返回选关
4. 注意：本版**通关画面上按 U / R 无效**，请按 Enter 返回选关。
5. 首次启动需解包，等 2~4 秒属正常。

二、macOS / Linux（跑源码）
---------------------------
    cd 递归之箱
    python3 -m venv .venv
    .venv/bin/python -m pip install pygame==2.6.1
    .venv/bin/python main.py

    跑测试： .venv/bin/python -m unittest discover tests

三、关卡
--------
    「测试」    最短 5 步：推箱 → 钻进方块 → 在内层把箱子推上判定点
    「吞食01」  最短 37 步：把方块吞进另一个方块的口，再进箱子把它推出来
    两个判定点都要被方块盖住，玩家还要站上 G 才能通关。

四、常见问题
------------
- 双击没反应/一闪而过：先关掉杀毒软件的误报拦截；或用命令行运行看报错。
- 中文显示成方块：目标机器缺少中文字体（Windows 一般自带微软雅黑）。
- 没有声音：当前版本没有音效（开题时列为选做）。
- 把箱子推进死角：按 R 重置本关即可。
