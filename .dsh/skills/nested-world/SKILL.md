# 嵌套世界

## 世界容器模型
- 每个箱子是一个 `WorldContainer`，持有 `inner_world`。
- `inner_world` 是独立格子地图，有自己的墙、空地、目标点，也可以有自己的箱子。
- 箱子被推动时，`inner_world` 整体随箱子坐标平移，内部实体相对位置不变。
- 玩家进入箱子内部后，外层世界暂停输入，当前活动世界切换为 `inner_world`。

## 口（door）：由内层地图边缘决定，不看方向字段
- 内层世界的**宽高必须是奇数**，四条边的**中心格**就是该边的口位（`entity.side_center`）。
- 某条边有口 ⟺ 该边中心格**不是墙**。中心格是墙 → 这条边进不去也出不来：
  **限制进出的是内层世界自己的边缘墙**，不是某个方向字段。
- 边缘环上除四个中心格外必须都是墙（`world.parse_world` 校验），避免“半个口”的歧义。
- 有几条边开口就能从几个方向进出；四面全墙的箱子是合法数据，但**进不去**
  （`entity.is_openable` 为 False）。

## 方向映射
- 朝方向 `d` 穿口 → 走的是**对侧**那条边的口：从下方往上推进去，就落在内层**底边**的中心口，
  继续朝 `d` 走就是往房间里走（`entity.entry_door(inner, d)`）。
- 站在内层某个口格上朝该口的**外侧方向**走就是出去（`entity.exit_side_at`）；
  外侧方向 = 该口所在边的方向（底边的口 → 朝下走）。
- 玩家与箱子**共用同一个口**：玩家从哪条边的口进出，箱子也从那条边进出。

## 箱子穿口（双向）
1. **外 → 内**：外层推箱时，链尾箱子贴着某个“口正对着它”的箱子 → 链尾箱子进入那个箱子的内部世界，
   落点 = 该侧的中心口格。
2. **内 → 外**：内层推箱时，箱子先被正常推到中心口格上（一步），**再推一步**（朝口的外侧方向）
   就把箱子推出到外层，落点 = 外层箱子该侧的相邻格（与玩家退出的落点完全相同）。
3. 外层落点是墙 → 推不动；那格有箱子 → 按推动规则推开（可连锁），推不开则整个动作无效。
4. 口格被箱子占住时（无论玩家进入还是箱子进来），**先把占位的箱子朝房间内侧推一格**；
   推不动（内侧是墙或箱子）则整个动作无效。

## 进入与退出
- **进入条件**：玩家站在箱子外侧朝箱子移动、箱子推不动，且这一侧的内层边缘有口
  （能推动时只推动、不进入，见 `push-box-logic`）。
- 进入落点 = 对侧边的中心口格；进入时把 `(world_ref, box_uid)` 压入返回栈，活动世界切换为 `inner_world`。
- **退出**：站在口格上朝该口的外侧方向走 → 退回外层，落点 = 外层箱子该侧的相邻格
  （墙 → 出不去；有箱子 → 推开后出去）。
- 搬运（吸入 / 推入别人的口 / 推出外层）共用同一套落点规则与 `validate_nesting()`；
  返回栈记 `(world_ref, box_uid)`，退出时现查箱子位置，所以箱子被移动也不会算错出口。

## 同层链同步与跨层冻结
- **同层**：推动时整条箱子链同时移动一格，内层世界不主动更新。
- **跨层冻结**：玩家进入内层后，外层世界冻结，不响应输入、也不自行更新。
  本实现**没有**“内层动作带动外层箱子”的镜像同步。
- 退出内层后，外层世界恢复。

## 测试要求
- `test_enter_box`：进入箱子，世界切换，落在对侧中心口格。
- `test_enter_requires_entrance_cell`：这一侧内层边缘是墙时进不去。
- `test_door_is_decided_by_inner_edge`：同一条边有口能进，多开一条边就能从两个方向进。
- `test_sealed_box_cannot_be_entered`：四面全墙的箱子进不去。
- `test_enter_when_door_occupied_pushes_it_inward`、`test_enter_refused_when_door_blocked_inside`：
  口被占时先把占位箱子往里推，推不动则拒绝。
- `test_exit_box`、`test_exit_to_open_tile`：从口走出去，落回外层。
- `test_exit_pushes_box`、`test_exit_blocked_by_wall`：外层落点被箱子占则推开，是墙则出不去。
- `test_box_moves_with_inner_world`：推动箱子，内部世界坐标整体平移。
- `test_push_box_into_inner_world`、`test_push_box_into_box`：箱子外 → 内，落点是中心口格。
- `test_push_box_out_of_inner_world`、`test_push_box_out_requires_clear_outer_cell`：箱子内 → 外。
- `test_push_box_deeper_nesting`：把已处于内部世界中的箱子再推入更深一层，深度正确累加（不设上限）。
- `test_reject_self_nesting`：禁止箱子直接或间接进入自己的 `inner_world`，操作被拒绝且状态不变。
