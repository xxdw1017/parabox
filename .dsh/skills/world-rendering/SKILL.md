# 多层世界渲染

## 视口与坐标
- 逻辑坐标一律是格子 `(x, y)`，渲染层负责换算成像素；**渲染层只读游戏状态，禁止修改**
  （RULE.md §一.8、AGENTS.md 分层依赖规则）。
- 窗口 1280×720，格子边长上限 `TILE = 64`；格子边长按
  `min(TILE, 可用宽 / 世界宽, 可用高 / 世界高)` 取整，保证小世界不放大、大世界不溢出。
- **纯色平涂**：只用 `pygame.draw` 画矩形 / 圆 / 线，不用贴图、不用渐变。

## 绘制规则
1. 只画**当前活动世界**：先铺地形（`#` 淡灰墙；空地按层取色——**外层深灰 / 内层深黄**），
   用底色勾 1px 网格线，再画判定点标记，最后画方块、玩家。
2. 判定点：`g` 画绿色**圆环**，`G` 画绿色**方框**。
3. 方块：含内部世界 = 黄、普通 = 蓝；默认描边近黑；
   **方块压在 `g` 上时描边换成白色、加粗，并再套一圈白色亮线**（判定点达成）。
4. 玩家：洋红实心圆；**站在 `G` 上时外面套一圈白色亮环**。
5. 带 `inner_world` 的方块，在其格子内缩 `max(2, tile×0.12)` 的矩形里**递归**画内层缩略图
   （缩略图里的空地同样是深黄）；缩略图等比缩放、不超出、居中，每深一层重复同样规则。
6. 缩略图的格子边长下限 `MIN_THUMB_TILE = 4`；低于该值时不再递归，只填一个深黄色块。
7. 每个方块把**有口的那几条边**画成缺口线（该边中心位置，白色）；玩家在内层时，
   把当前活动世界的口格用白色描出来，让人一眼看见能从哪条边出去。
8. 活动层高亮：给当前活动世界的外框描 `#F5A623`；玩家所在层级用面包屑文字表示（如 `b1 › b1a`）。
9. HUD：关卡名、步数、操作提示；通关时叠半透明遮罩 + 通关文案与步数。

## 可读性硬指标（写成 unittest，改配色时必须仍然通过）
两种地面都要查（外层深灰 `#2A2E33`、内层深黄 `#453A0D`）：
- **墙 / 方块（黄、蓝） / 口 / 玩家 / 判定点 / 亮边 vs 两种地面**
- 阈值：墙与方块 ≥ 3.0:1（大块色，且方块有近黑描边兜底）；
  玩家、判定点、亮边、口 ≥ 4.5:1
- HUD：正文 `#EBEEF5` 与次要文字 `#98A2B8` vs 世界外底色 ≥ 4.5:1

## 验收方式
渲染是给人看的：**实现方看不到渲染结果时，任何配色 / 比例改动都要先出对照图再定稿**；
代码里只保证“对比度达标 + 几何不重叠 + 不改游戏状态”，观感由人眼确认。
