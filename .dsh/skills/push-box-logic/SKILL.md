# 推箱子逻辑

## 核心规则
玩家移动时，沿移动方向检查箱子链：
1. 从玩家前方格子开始，收集连续相邻的箱子，形成 `box_chain`。
2. 若 `box_chain` 为空，玩家直接移动到前方空格。
3. 若 `box_chain` 非空，检查链尾箱子前方的格子：
   - 若是墙或不可推动实体，整条链不移动，玩家也不移动；
   - 若是空地 / 目标点，整条链同时向前移动一格，玩家也向前移动一格；
   - 若是**另一个箱子朝向我们的口**（该箱子在面朝我们这条边上有口），链尾箱子被推进它的内部世界，
     落点 = 那个箱子的该侧中心口格，其余箱子前移一格；
   - 若当前在内层世界、且链尾箱子正站在口格上、推动方向就是该口的**外侧方向** → 该箱子被推**出**到外层。
4. 整条链推不动时，检查是否触发**吸入**（见下节）；不触发则本步不产生任何移动。
5. 移动完成后，所有被移动箱子的 `inner_world` 坐标随之平移（不重新计算）。

## 推不动时的两个分支
被推的箱子 A（玩家紧邻的那个）推不动时，按顺序判定：
1. **吸入**：A 的那条边（推动方向 `d` 所对应的边）**有口**，且口上顶着推不开的箱子 B
   → B 连同其 `inner_world` 被吸入 A 的内部世界，落点 = A 该侧的中心口格；
   本步玩家不移动，其他箱子不移动。
   - 这就是「再推一步，口把顶墙的箱子吸进去」：第一步推不动（A 顶住 B、B 顶墙），
     第二步把 B 吸进去；吸入后 A 前方空出，继续推就能推走 A。
   - 口格上本来就停着箱子时，先把那个箱子朝房间内侧推一格；推不动则本次吸入无效。
2. **玩家进入**：不满足吸入条件时，本步不产生任何移动；玩家能否进入 A 由 `nested-world`
   的「进入与退出」判定（站在口对应的外侧格、朝 A 移动、且 A 推不动）。

## 重要边界
- 口由**内层地图边缘**决定，不看方向字段：内层宽高为奇数，四条边的中心格是口位，
  中心格是墙 → 这条边进不去也出不来（见 `nested-world`）。
- 箱子可以双向穿口：外层的箱子能被推进别人朝向它的口；内层的箱子能站在口格上再推一步推出到外层。
- 嵌套不设层级上限：箱子进入任意层数都合法；唯一硬校验是自引用 / 循环嵌套，交给 `nested-world`。
- 玩家不能和箱子重叠（入口被占时先推占位箱子；出口被占时先推开）。

## 测试要求
- `test_push_single_box`：推一个箱子。
- `test_push_box_chain`：连续三个箱子，同时移动。
- `test_push_chain_blocked_by_wall`：链尾是墙，整条链不动。
- `test_push_box_into_inner_world`：链尾箱子被推进别人朝向它的口（外 → 内）。
- `test_push_box_into_box`：两个箱子的链推入口，贴着口的那个进去、其余前移。
- `test_push_box_out_of_inner_world`：内层箱子站在口格上再推一步，推出到外层（内 → 外）。
- `test_push_box_out_requires_clear_outer_cell`：外层落点被顶死时推不出去。
- `test_swallow_box_at_entrance`：口顶着推不开的箱子时，再推一步把它吸入内部世界。
- `test_swallow_requires_entrance_facing_push`：推动方向上没有口时不吸入、只推不动。
- `test_no_swallow_when_chain_can_move`：链能推动时正常推走，不触发吸入。
